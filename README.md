# ILBE Page Redesign

A modern redesign of the **Ibadan Live Branding Event (ILBE)** registration page — transforming a plain text-only page into a polished, premium web experience.

## The Brief

The original page was pure unformatted text with no design, hierarchy, or visual identity. The goal: create a modern, scannable, beautifully designed registration page with clear CTAs, calm colors, and segmented information.

## Six Design Variations

Each variation explores a completely different aesthetic to find the perfect fit for the event's identity.

### 1. Variation A — Editorial / Magazine
> Dark, dramatic, serif-heavy, luxury print aesthetic.
- **Vibe:** High-end conference, Vogue-like typography.
- **Tech:** Playfair Display font, grain texture, parallax effects.

### 2. Variation B — Pill / Rounded
> Soft, friendly, contemporary SaaS aesthetic.
- **Vibe:** Approachable, modern product landing page.
- **Tech:** Animated gradient blobs, rounded cards, "pill" shapes.

### 3. Variation C — Flat Negative Space
> Minimal, Swiss-inspired, geometric precision.
- **Vibe:** Ultra-clean, art gallery, architectural.
- **Tech:** Monospace accents, marquee scrolling text, structural grid lines.

### 4. Variation D — Neo-Brutalist
> Bold, high-contrast, raw, vibrant borders.
- **Vibe:** Edgy, high-energy, youth-focused, "anti-design".
- **Tech:** Thick black borders, hard shadows, marquee strips, Archivo Black font.

### 5. Variation E — Glassmorphism / Aurora
> Dark mode, glowing gradients, frosted glass.
- **Vibe:** Futuristic, premium tech, ethereal.
- **Tech:** `backdrop-filter: blur`, floating orb animations, glowing text.

### 6. Variation F — Bento Grid / Modular
> Structured, organized, Apple-style grid layout.
- **Vibe:** Professional, organized, trustworthy.
- **Tech:** Masonry CSS grid, rounded cards, interactive hover states.

## How to View

Open any `index.html` file in your browser. All variations are self-contained with no build steps required.

```
├── variation-a/  (Editorial)
├── variation-b/  (Rounded)
├── variation-c/  (Swiss)
├── variation-d/  (Neo-Brutal)
├── variation-e/  (Glass)
└── variation-f/  (Bento)
```

## Tech Stack

- **HTML5** (Semantic structure)
- **CSS3** (Variables, Grid/Flexbox, Animations)
- **Vanilla JavaScript** (Scroll reveals, interactions)
- **Fonts** via Google Fonts (Playfair, Inter, Outfit, Space Grotesk, Archivo)
